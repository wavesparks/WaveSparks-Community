| 同一人在多种匹配中重复、不好分辨 | 合伙人、协作者、导师使用不同颜色，并说明同一人可以符合多个类别。 |

| 匹配输入从个人资料预填 | 未保存的活动偏好从个人资料预填，可修改；已保存的活动偏好优先。 |
| Arjun 填 edtech 仍然列出所有人 | 当前活动目标优先；明确的对方要求检查资料/可提供能力中的证据，支持 education technology 别名和原文重复 who。 |
| Maya 填 CS 和 Python 仍然列出所有人 | 同时要求 CS/编程背景及 Python 证据，不符合要求的候选人被排除。 |
| Kate 修改目标、类别没有正确更新 | 当前活动类别覆盖旧的全局寻找类别；保存后完成重算再返回页面，失败时隐藏旧结果并提示重试。 |
| 接受介绍后没有回复入口 | 接受后显示邮件回复和有效 WhatsApp 号码的聊天入口；未接受时不展示联系方式。 |
